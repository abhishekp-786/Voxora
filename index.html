First-use setup

Install dependencies with python -m pip install -r requirements.txt and run python server.py. The first transcription downloads the open Whisper Tiny model (~150 MB); speech recordings are sent only to the local service.

Production readiness checklist

Recommended next steps before handling real customer data

01Secure servicesMove integrations behind authenticated APIs; encrypt data in transit and at rest; define retention and consent policies.
02Reliable voice stackAdd streaming telephony, managed STT/TTS, interruption handling, monitoring and human handoff.
03Scale safelyUse stateless services, queues, tenant isolation, rate limits and regional autoscaling; load-test toward 100,000 users.
